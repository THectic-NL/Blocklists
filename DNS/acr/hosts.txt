# ACR (Automatic Content Recognition) Blocking List
#
# Automatic Content Recognition is the fingerprinting built into the TV itself.
# The set samples what is on screen or the audio going through it, turns that into
# a hash, and ships the hash to the vendor, which matches it against a reference
# catalogue. The result is a second-by-second log of everything you watch, including
# content from an HDMI console, a Blu-ray player or a laptop that never touched the
# internet. That log is then sold or used for ad targeting.
#
# This list is deliberately narrow. It targets the fingerprint ingest endpoints and
# the ACR vendors themselves, not the app store, firmware updates or streaming apps,
# so a TV keeps working while the viewing log stops leaving the house.
#
# Covered:
# - Samsung ACR (samsungacr.com, acr-*-prd.samsungcloud.tv)
# - LG Ad Solutions and Alphonso, the ACR business LG bought in 2021
# - Vizio Inscape (inscape.tv, tvinteractive.tv)
# - Samba TV, embedded in ~24 TV brands including Sony and Panasonic
# - Roku ad and measurement endpoints
# - Nielsen and INFOnline measurement panels that ingest ACR data
# - smartclip, Yume, SpotX and other CTV ad infrastructure fed by ACR segments
#
# The LG regional hosts were found by enumerating LG's per-country endpoints; each
# one is an individually provisioned DNS record, not a wildcard.
#
# ACR is opt-in on paper. In practice it is enabled during setup by a screen most
# people click through, and a firmware update can switch it back on. Blocking it at
# the resolver is the only setting the TV cannot reset.
#
# Format: 0.0.0.0 domain.com (hosts file format)
# Last updated: 2026-09-17
#
# Total domains: 765
#
